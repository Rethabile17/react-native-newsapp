# 🗞️ React Native News App

A sleek and modern mobile news app built with React Native and Expo. The app fetches and displays the latest news headlines, offering a clean reading experience for users on the go.

## 📰 Features

- 🧠 Fetch and display real-time news
- 🧭 Clean and responsive UI
- 🌙 Dark/light mode support (optional)
- 📱 Built with Expo for easy development

## ⚙️ Tech Stack

- React Native
- Expo
- News API (or mock data)
- Axios or Fetch API
- React Navigation (if used)
